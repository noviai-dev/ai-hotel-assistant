# 产品范围与 MVP

## 目标用户

- 总经理/业主：查看经营变化、风险和待决策事项
- 收益管理/市场人员：查看需求、竞品与渠道建议
- 客服/前台：处理咨询、服务请求和升级工单
- 品牌运营：维护 GEO 问题集并查看巡检结果

## MVP 功能

### 市场决策助手
- 统一酒店、房型、日期、可售房量、价格和预订数据
- 展示预订节奏与历史同期对比
- 登记竞品价格快照（首版支持 CSV/人工录入）
- 生成带理由、数据来源、置信度和有效期的价格/渠道建议
- 首版只给建议，不自动改价或向渠道发布

### GEO
- 酒店可配置品牌、官网 URL、竞品和多语言问题集
- 每轮巡检保存模型/渠道、提示词版本、回答、提及、引用 URL 与时间
- 展示品牌提及率、引用来源和竞品对照
- 输出人工可读的巡检报告
- 采集方式与数据许可需在实施前确认；先用适配器接口，不绑定未确认的第三方方案

### AI 客服助手
- 覆盖预订前、入住前、住中、离店后常见咨询
- 酒店知识库问答并返回引用片段
- 将送物、报修等意图转成待确认工单
- 低置信度、投诉、退款/安全等高风险请求转人工
- MVP 先接官网聊天入口；OTA、PMS、CRM、消息渠道作为后续适配器

## 不纳入首版

自动调价发布、自动退款/订单变更、未经许可的 OTA 抓取、无人工确认的高风险对客承诺。

## 关键验收

- 每条建议和回答可追溯到数据/知识来源
- 跨酒店租户数据隔离
- 客服升级时携带会话摘要与工单上下文
- GEO 每条结果能复现采集条件
